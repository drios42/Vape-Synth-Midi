# Vape-Synth-Midi
Repurposing discarded vapes to make sound.  This second iteration of the Vape Synth communicates to a DAW using MIDI over BLE.  Hardware used is repurposed vape parts, buttons, and a Seeed Xiao ESP-32 S3

Current version requires downgrading to the following board and library versions:
- esp32 3.3.0 board definition
- NimBLE-Arduino v1.4.3
- ESP32-BLE-MIDI v0.3.2
